# Луч — домашние диафильмы

Статический сайт для удобного просмотра диафильмов на компьютере и iPad/iPhone.

Возможности: каталог, поиск, рейтинг, избранное, запоминание кадра, управление с клавиатуры и свайпами.

Изображения загружаются с источника при открытии истории. Для просмотра нужен интернет. Личные кадры и настройки сохраняются в браузере на устройстве.

Публикация: GitHub Pages, ветка `main`, корневая папка. Сборка не требуется.
