# Луч — домашние диафильмы

Статический сайт для удобного просмотра диафильмов на компьютере и iPad/iPhone.

Сайт: https://ibivanov80.github.io/luch-diafilmy/

Возможности: каталог с иллюстрированными превью, поиск, рейтинг, избранное, запоминание кадра, управление с клавиатуры и свайпами. Тап справа открывает следующий кадр, слева — предыдущий, по центру — возвращает управление и выходит из полноэкранного режима.

Порядок кадров хранится на сайте в `frames.json`. Оригиналы лежат в [папке «Луч — оригиналы диафильмов» на Google Диске](https://drive.google.com/drive/folders/11xv1GFO61a-bveJ0oGqXZLSJltr0YB4i). У каждого диафильма своя папка с пронумерованными файлами. При перелистывании браузер получает полноразмерные изображения с Google Диска. Поле `page` в списке кадров указывает на архив, откуда взяты сканы. Для просмотра нужен интернет. Личные кадры и настройки сохраняются в браузере на устройстве.

Публикация: GitHub Pages, ветка `main`, корневая папка. Сборка не требуется.

Превью каталога хранятся в `covers/`. Обновление превью: `python3 scripts/refresh-covers.py --refresh` (нужен Pillow). Для личных диафильмов используется первый сохранённый кадр.
